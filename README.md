# Cloudflare Grok Provider Router Kit

Cloudflare AI Gateway makes multimodal provider routing feel like product infrastructure instead of one-off API plumbing.

Inspired by: https://x.com/xai/status/2062294202625696081

## What it contains
- `artifact-package/` — Obsidian package note mirror
- `prototype/` — static artifact builder
- `infographic/` — workflow explanation
- `improvement-loop/` — recurring improvement tracker

## Quickstart
Open `prototype/index.html` in a browser.

## Latest improvement
- `prototype/Provider Router Promotion Decision Card.md` — decision gate for promote route / workflow-specific only / iterate / hold.
