# Provider Router Recipe Builder

Source: https://x.com/xai/status/2062294202625696081

## What it demonstrates
A small local-first builder that turns `Grok Models on Cloudflare AI Gateway` into a concrete artifact brief Vinay can copy into a repo issue, agent task, or product note.

## How to run/open
Open `index.html` in a browser. No build step required. Inputs persist in localStorage.
